   - Returns score (0-100), grade, recommendation

================================================================================
SCORING SYSTEM
================================================================================

| Score   | Grade     | Recommendation | Action      |
|---------|-----------|----------------|-------------|
| 85-100  | EXCELLENT | STRONG_HIRE    | Hire        |
| 80-84   | GOOD      | SHORTLIST      | Interview   |
| 70-79   | MODERATE  | MAYBE          | Maybe       |
| 55-69   | WEAK      | REJECT         | Reject      |
| 0-54    | POOR      | REJECT         | Reject      |

Scoring Formula (100 points):
- Technical Skills Match: 55 points (PRIMARY)
- Experience Relevance: 25 points
- Domain Alignment: 20 points

================================================================================
CRITICAL: ANTI-HALLUCINATION RULES
================================================================================

The LLM was hallucinating skills (claiming AI/ML person had React/JS when they didn't).

FIX IMPLEMENTED in jd_cv_prompts.py:

1. STEP A: Extract ALL skills from CV first (list them explicitly)
2. STEP B: List JD required skills
3. STEP C: Match one-by-one with YES/NO verification
4. STEP D: Calculate actual percentage

RULES:
- Python != JavaScript (different languages)
- TensorFlow != React (ML vs UI library)
- MongoDB != MySQL (different databases)
- ONLY count skills EXPLICITLY mentioned in CV text

EXAMPLE:
- CV: [Python, SQL, TensorFlow, Keras]
- JD: [React, JavaScript, HTML, CSS]
- Result: 0% match (ZERO overlap) = Score 40-50

SESSION: January 8, 2026 (Part 2) - INTEGRATED MCQ GENERATION

NEW FEATURE: Generate MCQ from JD-CV Match Results

After completing JD-CV matching, users can now click "Generate Interview Questions"
to get personalized MCQ questions based on the match analysis.

Files Created:
- app/prompts/integrated_mcq_prompts.py    # MCQ generation prompts
- app/services/integrated_mcq_generator.py # MCQ generation service

Files Modified:
- app/routers/matching.py                  # Added /api/v1/generate-mcq-from-match endpoint
- app/static/jd_cv_match.html              # Added MCQ button and question display UI
- app/services/openrouter_client.py        # Fixed JSON parsing for control characters

HOW IT WORKS:
1. User performs JD-CV match as usual
2. After results display, "Generate Interview Questions" button appears
3. Click button → System takes match data (matched skills, JD, CV analysis)
4. LLM generates 8 personalized questions:
   - HARD questions for skills candidate claims to be strong in
   - MEDIUM questions for other matched skills
5. Questions display with:
   - Skill being tested (e.g., "React.js", "JavaScript")
   - Difficulty level (MEDIUM/HARD)
   - Why this difficulty (e.g., "CV shows strong React experience")
   - 4 options (A, B, C, D)
   - Show Answer button with explanation

API ENDPOINT:
POST /api/v1/generate-mcq-from-match
Body: {
    "job_title": "Frontend Developer",
    "jd_skills": ["React.js", "JavaScript", ...],
    "cv_skills": ["React", "Node.js", ...],
    "matched_skills": ["React.js", "JavaScript"],
    "missing_skills": ["HTML5", "CSS3"],
    "skill_match_pct": 60,
    "strengths": ["Strong React experience"],
    "interview_focus": ["CSS skills"]
}

HOW TO RUN
================================================================================

1. Install dependencies:
   pip install -r requirements.txt

2. Set up .env (copy from .env.example):
   OPENROUTER_API_KEY=your_key_here

3. Start server:
   uvicorn app.main:app --host 0.0.0.0 --port 8000

4. Access:
   - Homepage: http://localhost:8000/
   - JD-CV Match: http://localhost:8000/jd-cv-match
   - Question Gen: http://localhost:8000/question-gen

================================================================================
API ENDPOINTS
================================================================================

POST /api/v1/jd-cv-match
  - Form data: jd_details (JSON string), capabilities (JSON string)
  - File: cv_file (PDF)
  - Returns: match_score, match_grade, recommendation, skill_analysis

POST /api/v1/generate-questions
  - JSON body: skills[], job_title, difficulty_distribution
  - Returns: questions[] with MCQ options
